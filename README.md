# Terminal Portfolio

An interactive terminal-style portfolio built with **Next.js**, **React**, and **TypeScript**.

Instead of navigating traditional pages, users explore the portfolio by running CLI-style commands in a simulated Windows command prompt.

---

## Features

* Typing animation with blinking cursor
* Clickable commands (no manual typing required)
* Command history rendering
* `clear` command to reset the terminal
* `run all` command to display all sections
* Devicon-powered skills display
* Desktop-optimized experience

---

## Available Commands

```
help
about
education
skills
skills -f
skills -b
skills -t
contact
clear
run all
```

Commands can be typed or clicked directly within the terminal output.
